    Reviewing place names

    Each box on the map is a label found by OCR. Correct the name as printed on the map, keeping its spelling, hyphens and question marks, then confirm. Work through the queue on the right; click any box to jump to it.

    Enter
    Confirm and go to the next label
    Alt+X
    Reject (not a place name, or misread noise)
    Alt+→ / Alt+←
    Skip ahead / go back
    Alt+M
    Join with another box: click a box whose words belong to this label (e.g. a name split in two)
    Alt+A
    Make this an alternate name of another label: click the main name (e.g. “(Beisan)” under “Beth-shean”)
    Alt+B
    Redraw this label’s box: drag on the map
    Alt+N
    Add a label OCR missed: drag a box round it
    Ctrl+Z
    Undo (when not typing in a field)
    Esc
    Cancel joining or drawing

    Kinds: height is a spot elevation (these will feed the elevation readout), graticule the degree figures in the margin (these will help georeference the map).
